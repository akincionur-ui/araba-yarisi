# Araba Yarışı

Tarayıcıda oynanan 3D araba yarışı oyunu (three.js).

**Oyna:** https://akincionur-ui.github.io/araba-yarisi/

## Kontroller
- W / ↑ gaz, S / ↓ fren ve geri, A D / ← → direksiyon, Boşluk el freni
- R yeniden başla, C kamera, B renk, G grafik kalitesi, M ses, Esc / P duraklat
